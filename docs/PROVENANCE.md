# MagiBoard implementation provenance

Recorded for the MagiBoard v0.3 hackathon prototype, November 15, 2026.

The Swift app, Python companion, object schema, renderers, graph parser, LaTeX parser and math layout, persistence layer, widget document protocol, catalog integration, and included example widgets were authored for this project with AI coding assistance. No third-party whiteboard implementation was cloned, forked, vendored, or copied into the app.

## Frameworks, runtime, and assets

The app uses Apple system frameworks: SwiftUI, UIKit, PencilKit, Core Graphics, CoreText, PDFKit, WebKit, Speech, AVFoundation, PhotosUI, UniformTypeIdentifiers, Security, and Foundation networking. System fonts and SF Symbols remain Apple assets. No external Swift package or JavaScript whiteboard/math library is bundled.

The toolbar's books button uses Apple's `books.vertical` SF Symbol. The app icon is a separate original drawing of three books and a four-point light, generated by `scripts/generate_icon.swift` from project-authored geometry. It does not contain copied SF Symbol paths or third-party artwork.

The equation implementation uses an original bounded parser, baseline-based layout, and native text/vector drawing. It does not embed Mathcha, MathLive, Mathlean, MathJax, KaTeX, or another third-party typesetter. Conventional mathematical notation and LaTeX command names inform the supported expression syntax; no external parser or layout implementation was copied. The live equation editor and its math accessory are original native UI.

The companion uses Python's standard library, macOS service-discovery tools, an externally installed Codex runtime, and an optional externally installed Databricks CLI. These external tools are not project-owned code. Codex protocol integration was checked against installed CLI help, the [official app-server documentation](https://learn.chatgpt.com/docs/app-server), and [official authentication documentation](https://learn.chatgpt.com/docs/auth). A generated protocol schema was inspected for integration research and is not shipped as source. The original Databricks adapter calls supported authentication and Files API interfaces; workspace configuration and account credentials are not included in the repository.

The welcome notebook and example widgets are original project content. Imported PDFs, images, text, retrieved web material, and model-generated content retain their respective provenance and applicable terms. Exporting a notebook does not transfer ownership of those materials.
